# Дизайн 01 — «Ночной город» с интерфейсом очков

Первая версия сайта, снята с боевой ветки 8 сентября 2026 по решению владельца.
Здесь лежит полная копия исходников на момент архивации: `src/`, прототип
и конфигурация сборки.

## Что это было

- Вход через кадр из ролика: кнопка «Войти», ролик посадки в кресло,
  экран загрузки с приборной панелью и фразой «Всё ограничено вашей фантазией».
- Комната из последнего кадра ролика стояла фоном на всех страницах,
  поверх неё — рамка стекла очков с засечками, рейками и телеметрией.
- Панели со стеклом, засечками по углам и всплытием при наведении.
- Карточка тарифа открывала окно с живым проволочным макетом возможностей
  пакета: прокрутка, форма, каталог, параллакс, страницы, админка, фильтры,
  блог, личный кабинет, дашборд.

## Что может пригодиться

- `src/components/entry/` — последовательность входа: кадр, ролик, загрузка.
- `src/components/tiers/DemoScene.tsx` — десять анимированных сцен-макетов.
- `src/app/globals.css` — утилиты HUD: стекло, засечки, развёртка, глитч.
- Материалы ролика остались в боевом `public/scene/`, здесь не дублируются.

Данные (тарифы, тексты, условия) в архиве тоже есть, но актуальная версия
живёт в боевом `src/data/` — оттуда и брать.
