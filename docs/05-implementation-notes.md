# Заметки по реализации

## Реализовано

Код написан строго по `docs/04-spec.md`. Сборка и линтер проходят чисто.

**Каркас**

- Next.js 16 (App Router), TypeScript, Tailwind CSS 4. Все шесть маршрутов
  генерируются статически: `/`, `/prostoy-sayt`, `/sredniy-funktsional`,
  `/chto-vhodit`, `/usloviya`, плюс 404.
- Шрифты Unbounded, Manrope и JetBrains Mono подключены через `next/font/google`
  и раздаются со своего домена — сторонних запросов при загрузке нет.
- Токены артбука «Ночной город» заданы один раз в `@theme` в `globals.css`.

**Вход**

- `EntryOverlay` — оверлей поверх готовой главной, а не отдельный маршрут.
  Состояния: стартовый кадр с кнопкой «Войти» → ролик → загрузка с фразой → снятие.
- Отметка о пройденном входе читается через `useSyncExternalStore`, поэтому
  на сервере оверлея нет и расхождения при гидратации не возникает.
  Новая вкладка показывает вход заново.
- Ролик отдаётся двумя дорожками: `scene.webm` (2,9 МБ) первым, `scene.mp4`
  (3,7 МБ) запасным для Safari. Обе без звука.
- Если браузер отказал в воспроизведении или файл не загрузился, оверлей
  переходит к экрану загрузки: застывшего кадра посетитель не увидит.
- При системной настройке «уменьшить движение» ролик пропускается.
- Пока оверлей на экране, прокрутка страницы под ним заблокирована.

**Данные**

- Восемь тарифов, десять пунктов состава, четыре этапа оплаты и правила правок
  лежат в `src/data/` и проверяются схемами Zod при импорте.
- Цена со скидкой нигде не хранится — считается от прайсовой в `lib/price.ts`.
  Проверено на сборке: 32 000 → 19 200, 150 000 → 90 000.
- Размер акции берётся из `NEXT_PUBLIC_PROMO_PERCENT` (по умолчанию 40).
  При нуле зачёркнутая цена не выводится, остаётся только прайсовая.
- Сумма долей по этапам оплаты сверяется с 100 при импорте данных.
  Сейчас 10 / 30 / 30 / 30 — проверено в собранном HTML.
- Дубли идентификаторов тарифов ловятся отдельной проверкой после разбора схемы.

**Интерфейс**

- Карточки тарифов на `<details>`: раскрываются без JavaScript, доступны
  с клавиатуры, открытыми могут быть несколько сразу.
- Превью-макет пакета рисуется из описания в данных, а не из разметки, —
  все восемь превью одного визуального языка.
- Кнопка Telegram одна на весь сайт, в закреплённой шапке. В карточках
  и в подвале её нет.
- Процент скидки в карточках не показывается: только зачёркнутая цена рядом с новой.

## Отложено (по договорённости)

- Форма заявки — в `docs/02-scheme.md` числится в разделе «Потом».
  Серверных маршрутов в проекте нет вовсе.
- Раздел с примерами работ — появится, когда наберутся проекты по акции.
- Отдельная страница под каждый тариф.
- Аналитика не подключается: сбора данных на сайте нет.
- Перегенерация ролика без запечённого HUD и вертикальный вариант для телефона —
  решено оставить как есть (`docs/03-prototype-notes.md`).

## Реализованные базовые меры безопасности

- Заголовки в `next.config.ts`: `Content-Security-Policy` (свои ресурсы,
  `form-action 'none'`, `object-src 'none'`), `X-Content-Type-Options: nosniff`,
  `Referrer-Policy: strict-origin-when-cross-origin`, `X-Frame-Options: DENY`
  и `frame-ancestors 'none'` — сайт нельзя встроить в чужую страницу и выдать
  за своё предложение.
- Внешняя ссылка на Telegram открывается с `rel="noopener noreferrer"`.
- Пользовательского ввода нет: ни форм, ни поиска, ни параметров запроса,
  влияющих на разметку. Поверхности для инъекций через ввод не существует.
- Секретов в репозитории нет. `.env.example` содержит только размер акции,
  токенов и ключей в проекте не появилось.
- `error.tsx` и `not-found.tsx` показывают оформленный экран без стеков вызовов
  и внутренних путей.
- Видео не блокирует вход: любая ошибка воспроизведения ведёт дальше, а не в тупик.

## Проверено

- `npm run build` — успешно, шесть статических маршрутов.
- `npx eslint .` — без замечаний. Правило на строковые `href` проверено отдельно:
  на `<a href="/prostoy-sayt">` линтер выдаёт ошибку и требует `ROUTES`.
- Собранный HTML: цены 25 000 → 15 000, 32 000 → 19 200, 40 000 → 24 000,
  50 000 → 30 000, 75 000 → 45 000, 100 000 → 60 000, 125 000 → 75 000,
  150 000 → 90 000; этапы оплаты 10 / 30 / 30 / 30.
- Оверлей входа в серверной разметке отсутствует, как и задумано.
- **Визуально в браузере не проверено.** Preview-инструмент этой сессии остаётся
  привязан к папке заказчика и поднимает чужой проект; проверка глазами
  на стороне владельца: `npm run dev`.

## Рекомендации

- Заменить статичный постер входа на первый кадр с лёгким наплывом: сейчас между
  кадром и началом ролика заметен щелчок — статус: ожидает решения пользователя.
- Предзагружать ролик только при наведении на кнопку «Войти», а не сразу:
  посетитель, пришедший за ценами, не будет качать 3 МБ впустую —
  статус: ожидает решения пользователя.
- Добавить `metadataBase` и картинку Open Graph: при отправке ссылки в мессенджер
  сейчас подтягивается только заголовок и описание — статус: ожидает решения пользователя.
- Прогонять `npm run build` в GitHub Actions на каждый пуш: проверки Zod и типов
  тогда сработают до деплоя, а не после — статус: ожидает решения пользователя.
